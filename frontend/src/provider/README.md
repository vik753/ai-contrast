## UI contract (English accessible names)

- Preset: `<select>` labelled "Provider"; option values are the `PresetId`s; default `free`.
- Model: textbox "Model" with a `<datalist>` of the preset's suggestions; absent for `free`.
- Custom only: `<details>` with summary "Advanced" holding textbox "Base URL". Absent for other presets.
- Key (not for `free`): `<input type="password" autocomplete="off">` labelled "API key". Checkbox "Remember on this device"; when checked, an element with `role="note"` shows the warning.
- Buttons "Test connection" and "Forget key". Success: `role="status"` with `provider.test.ok`. Failure: `role="alert"` with `provider.error.<code>`.
- Free mode: notice `provider.free.notice` (which provider processes the text, its data policy) and `provider.free.turnstileNotice` (a Cloudflare check loads). Gemini: `provider.gemini.hint` and `provider.gemini.dataUse`.
- Free flow: no iframe on page load. "Test connection" in free mode mounts `TurnstileFrame`; the check request is sent when a valid token message arrives; afterwards the token is dropped and a reset is posted (one token, one use). Leaving free mode unmounts the iframe.
- The app never creates a `<script>` from Cloudflare.

## Second origin (the frame page)

- Separate Vite entry: `frontend/turnstile/turnstile.html` (only an external module script `main.ts`, no inline script), logic in `src/turnstile-frame/`:
  - `frameController.ts`: `createFrameController({ appOrigin, parent, widget })` returns `{ onWidgetToken(token), onMessage(ev) }`. `parent` is the parent window (`postMessage(msg, targetOrigin)`); it posts `{ type: "turnstile-token", token }` to `appOrigin` (never `"*"`). `onMessage` acts on `{ type: "reset" }` only when `ev.origin === appOrigin` and `ev.source === parent`; everything else is ignored.
  - `siteKey.ts`: `resolveSiteKey({ DEV?: boolean; VITE_TURNSTILE_SITE_KEY?: string }): string`. Development without a key gives Cloudflare's test key `1x00000000000000000000AA`; production without a key throws; production never returns a test key.
- Config `frontend/vite.turnstile.config.ts` (root `turnstile`, port 5174, `outDir` `../dist-turnstile`). npm scripts `dev:turnstile` and `build:turnstile`. Dev: run `npm run dev` (5173) and `npm run dev:turnstile` (5174). Env: app `VITE_TURNSTILE_FRAME_ORIGIN`; frame `VITE_TURNSTILE_APP_ORIGIN`, `VITE_TURNSTILE_SITE_KEY`.
- Headers: `frontend/turnstile/public/_headers` for the frame project; app `frontend/public/_headers` `frame-src` is one origin or the placeholder `__TURNSTILE_FRAME_ORIGIN__` (replaced at deploy); the frame file uses `__APP_ORIGIN__` for `frame-ancestors`.
